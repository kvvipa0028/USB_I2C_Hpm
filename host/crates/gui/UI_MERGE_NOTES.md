# 上位机 UI 说明（BusStudio × Magpie）

范围：只改 `host/crates/gui`。USB 协议、固件、`usb-i2c` crate 都没动。

## 哪些会走 USB，哪些只在本窗口

线上只有两个命令，和改版前一样：

| 命令 | 何时发出 | 发起位置 |
| --- | --- | --- |
| `CMD_PING` (0x01) | 点「连接」时一次，读回固件和协议版本 | 顶栏设备条、设备连接页 |
| `CMD_I2C` (0x10) | I2C 主机页点「写入」「读取」「写后读」 | I2C → 主机 |

列设备（刷新）只枚举 USB，不向设备发命令；「断开」只在本机释放接口。

其余都只在本窗口：

| 位置 | 行为 |
| --- | --- |
| I2C 主机：扫描地址、总线恢复 | 按钮置灰，悬停「当前固件无此命令」 |
| I2C 主机：端口、速率 | 只读，显示 I2C0 · 主机、100 kHz，标「固定」，悬停说明当前固件固定 |
| I2C 从机：从机地址、256 B 寄存器表 | 本窗口编辑，初值全 0（同 slave_proto 复位后），关闭后不保留 |
| I2C 从机：下发到设备、从设备读回 | 按钮置灰，悬停「当前固件无此命令」 |
| SPI 整页 | 配置、MOSI 编辑、「执行收发」把一笔事务记入本次会话；不发 USB，记录没有 MISO 数据，结果列标「本地」 |
| PWM 整页 | 配置、占空比滑杆、波形预览（按设置画的示意，标「非实测波形」）；「应用配置」把当前设置记入配置记录，不发 USB |

## 壳

- 顶栏设备条：品牌、设备弹出字段（状态圆点 + 序列号 + USB 速率 + chevron）、固件徽章（从 PING 回复解析固件和协议版本）、刷新、连接/断开。
- 底栏状态条：连接状态、空闲/进行中、最近结果的软徽章；右端随页面变化：设备连接和 I2C 显示「I2C0 · 100 kHz（固件固定）」，SPI 显示「SPI · 本地会话」，PWM 显示「PWM · 配置预览」。
- 侧栏：设备连接（带状态圆点），然后「功能」组 I2C / SPI / PWM，三项都不带标签。底部「外观」：浅色 / 深色 / 跟随系统。侧栏只有这四项，没有扩到 BusStudio 的 16 个模块。

## 页面

所有功能页同一结构（取自 BusStudio）：页头（标题、徽章、一行说明、右侧操作）；左栏「接口配置」卡 + 下方 ⓘ 提示；右栏顶部一条摘要带，然后是操作卡、结果卡、记录表。窄于断点时两栏改为上下排。

- **设备连接**：设备列表卡（逐行选择，标出已连接），连接信息（状态、序列号、固件、协议版本、端口、速率、单次上限）。
- **I2C · 主机**：
  - 左栏：端口、速率只读；目标地址、读取长度可填，输入有误就地提示。
  - 右栏：
    - 摘要带：本次会话的事务数、应答成功数、接收字节数，都是真实统计。
    - 「读写事务」：HEX 输入，写入、读取、写后读。
    - 「结果」：hex dump，可复制 HEX。
    - 「事务记录」：本次会话，最新在上，最多 200 条，点行查看。工具行放「扫描地址」「总线恢复」（置灰）和「清空」。
- **I2C · 从机**：
  - 左栏：端口（只读）、从机地址、寄存器表规格、访问方式；「与设备同步」两个置灰按钮，一句「表格保存在本窗口，关闭后不保留」。
  - 右栏：
    - 摘要带：从机地址、已改字节、非零字节、光标偏移。
    - 256 B hex 网格：点格子选中，键入两位十六进制改值，方向键移动；改过的格子标 accent 软底。带 ASCII 列和检查器；全部 00 / 全部 FF / 递增 / 还原 / 复制 HEX。
- **SPI**：
  - 左栏：硬件通道（SPI0/1）、时钟频率（500 kHz–8 MHz）、Mode 0–3、片选（CS0/1）、字长（8/16 bit）；「高级参数 3 项」可展开：位序、片选有效电平、填充字节（16 bit 字长下奇数个字节用它补齐）。
  - 右栏：
    - 摘要带：事务数、MOSI 字节、按时钟估算的总线时间。
    - 「发送 MOSI」：HEX 输入、字节计数、「执行收发」，旁边一枚当前片选 · 模式 · 时钟的徽章。
    - 「事务详情」：配置快照、MOSI（16 bit 时按字分组）、MISO「本地记录，无回读数据」、时序（时钟数、估算时长、CPOL/CPHA、片选电平）。
    - 「事务记录」：列为 时间、片选、长度、MOSI、MISO、结果。
  - 页头「恢复默认」只重置配置。
- **PWM**：
  - 左栏：输出通道（PWM0/1）、输出频率（1 Hz–1 MHz）、占空比（0–100，一位小数）、有效电平、停止状态（低 / 高 / 高阻）；「高级参数 2 项」：对齐方式（边沿 / 中心）、启动延时。卡底显示「尚未应用 / 参数有修改 / 已应用 · 时间」和「撤销修改」。
  - 右栏：
    - 摘要带：配置周期、高电平时间、低电平时间（随有效电平换算）。
    - 「输出配置预览」：大号频率和周期、占空比数值和滑杆（拖动或点轨道，聚焦后 ←/→ 每步 1%），四个周期的方波示意，随有效电平反相、随对齐方式居中。
    - 「配置记录」：时间、通道、频率、占空比、有效电平、事件。首次为「应用配置」，之后写出改了哪几项，如「修改 占空比、有效电平」。
  - 页头：「应用配置」（墨色主按钮，有改动时可点）、「恢复默认」。

## 与 BusStudio / Magpie 的取舍

- 主色沿用 `tokens()` 的 Magpie indigo（浅 `#4f46e5` / 深 `#a5b4fc`），**没有**用 BusStudio 稿的 `#6657db`。accent 给焦点、打开中的弹出字段、选中/改过的格子、滑杆和 PWM 波形线。
- 主按钮用墨色（fg），次按钮白底描边，工具按钮无底。状态一律用圆点和软徽章，没有彩色左边条。
- 从 BusStudio 拿的是结构：顶栏设备条、页脚状态、「配置 | 工作区」两栏、面板头 + 细线、字段行、高级参数折叠、摘要带、ⓘ 提示、事务表和表脚、PWM 预览布局。没有搬它的横向页签、三步向导、演示数据和「保存配置」。
- SPI/PWM 的选项范围（通道名、时钟档、频率上限）是界面上的取值，不对应某块芯片的能力。
- BusStudio 的 HTML 没有进仓库。
- 深浅色选择存在一个单词的小文件里（Linux `$XDG_CONFIG_HOME` 或 `~/.config` 下的 `usb-i2c/theme`，Windows `%APPDATA%\USB-I2C\theme`，macOS `~/Library/Application Support/USB-I2C/theme`）。

## 新增控件（`widgets.rs`）

`pick`（配置行里的弹出选择）、`unit_edit`（带单位的数字框）、`disclosure`（高级参数折叠行）、`summary_strip`（摘要带）、`note`（ⓘ 提示）、`table_foot`（表脚）、`slider`（Magpie 样式滑杆）。

## 协议与行为

- worker 的 `Job` / `Event` 没变：`Refresh`、`Connect`（PING）、`Disconnect`（只在本机）、`Transfer`（I2C）。SPI、PWM 页不碰 worker。
- 「读取」只读，不看写入框，与 CLI 的 `read` 一致。
- 已打开的设备不在刷新结果里时：顶栏标「不在列表」，圆点变红，「断开」一直可点，主机读写按钮禁用。
- 改连另一台设备失败时保留原来打开的设备。

## 中文字体

- 内置 `assets/fonts/NotoSansSC-UI.otf`：Noto Sans CJK SC Regular 按 `src/` 里实际用到的字（加常用中文标点）裁成子集，约 110 KB / 296 个字符；许可证 SIL OFL 1.1，见同目录 `OFL.txt`。
- 加中文文案后重跑 `assets/fonts/subset.sh`（需要 fonttools 和 Noto Sans CJK）。测试 `fonts::tests::subset_covers_ui_text` 扫描全部源码，有字不在子集里就失败。
- 子集排在 egui 自带字体之后，英文和数字仍用 egui 字体；子集外的字交给 eframe 的系统字体回退。只有 Regular 一个字重。

## 验证

- `cargo test -p usb-i2c-gui`（22 个测试）、`cargo clippy -p usb-i2c-gui --all-targets -- -D warnings`、`cargo fmt --check` 通过。egui 0.37 需要 Rust ≥ 1.95，要用 rustup 的 stable，系统自带的 cargo 1.85 不行。
- Linux（Xvfb，wgpu GL 后端）跑过窗口：浅/深色；设备、I2C 主机、I2C 从机、SPI、PWM 五页；900 px 窄窗口；SPI 执行和 16 bit 补齐；PWM 拖动和点击滑杆、弹出选择、有效电平反相、两次应用后的配置记录；各页空闲时 CPU 为 0。
- **没有接真机测试**：连接、PING、I2C 读写走原来的 `Bridge` 代码，改动只在 UI 侧，还需要在 HPM6300EVK 上过一遍。

## 代码结构

```
src/main.rs        入口和窗口尺寸
src/app.rs         App 状态、事件处理、壳的组装（顶栏 / 底栏 / 侧栏 / 页面）
src/worker.rs      Job / Event / Op / Transfer 与 USB 工作线程
src/theme.rs       Tokens 与 egui Visuals、外观选择
src/fonts.rs       内置中文字体子集
src/widgets.rs     页头、面板、字段行、按钮、弹出字段/选择、分段控件、徽章、表格、摘要带、提示、滑杆、页脚、两栏布局
src/nav.rs         侧栏
src/device.rs      顶栏设备条、设备连接页
src/i2c/mod.rs     I2C 工作台（主机 / 从机页签）、固定值与置灰按钮的悬停文案
src/i2c/master.rs  主机页、事务记录
src/i2c/slave.rs   从机页、256 B hex 网格
src/i2c/parse.rs   地址、字节、长度解析（规则同 CLI），hex 与时间格式
src/spi.rs         SPI 页（本地事务记录）
src/pwm.rs         PWM 页（波形预览、本地配置记录）
```
