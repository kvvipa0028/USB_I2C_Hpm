# 上位机 UI 说明（BusStudio × Magpie）

本文描述上位机 UI 行为。单桥会话、USB 异常恢复和演示页计时的后续修复见 [`docs/host-reliability.md`](../../../docs/host-reliability.md)。PWM / 频率捕获合页的后续行为见 [`docs/pwm-frequency-capture.md`](../../../docs/pwm-frequency-capture.md)。I2C 的当前控制合同见 [`docs/control-protocol-v1.md`](../../../docs/control-protocol-v1.md)，其余演示页边界保持不变。

## 哪些会走 USB，哪些只在本窗口

I2C 经同一 worker 调用当前选择的 USB 设备或显式离线模型；按能力开放命令：

| 命令 | 何时发出 | 发起位置 |
| --- | --- | --- |
| `CMD_PING` (0x01) | 点「连接」时用于同步会话、读回固件和协议版本 | 顶栏设备条、设备连接页 |
| `CMD_I2C` / `I2C_PORT` (0x10/0x11) | 单次主机传输或显式循环；legacy 只开放 CH0/100k | I2C → 主机 |
| `CAPABILITIES` / `CONTROL_CAPS` (0x02/0x03) | 连接时查询能力；仅精确旧 BadRequest 降级 | 连接流程 |
| `I2C_BATCH` (0x12) | 每端口一笔事务，独立结果 | I2C → 双端口批次 |
| `GET_PORT_STATE` / `CONFIG_PORT` (0x13/0x14) | 回读状态、用 generation 比较应用配置草稿 | I2C → 端口控制 |
| `TABLE_READ` / `TABLE_WRITE` (0x15/0x16) | 从机表读回及 CAS 片段下发 | I2C → 从机 |
| `PROBE` / `RECOVER` (0x17/0x18) | 逐地址扫描、有界总线恢复；失败与部分结果明确显示 | I2C → 端口控制 |
| `FRONTEND_GET` / `FRONTEND_SET` (0x19/0x1A) | 按能力查询/应用；当前 EVK 不支持，无伪测量 | I2C → 端口控制 |

列设备（刷新）只枚举 USB，不向设备发命令；「断开」只在本机释放接口。

其余都只在本窗口，不碰 `worker` / `Job` / `Bridge`：

| 位置 | 行为 |
| --- | --- |
| I2C 主机：保存配置、暂停显示 | 保存配置只存本窗口快照；暂停显示只冻结列表 |
| I2C 从机：未下发的表草稿 | 按端口保留草稿；只有显式下发且设备确认后才算提交。断开清除快照代次，重连不自动下发 |
| SPI | 「执行收发」（单次或循环）把一笔事务记入本次会话；没有 MISO 回读，列名「MISO（无回读）」 |
| PWM / 频率捕获 | 输出与捕获独立启停的本地演示、固定捕获示例、已应用配置对比、参数重建时序及 CSV 复制；不发送 USB |
| CAN | 开始/暂停接收启停本页的演示报文生成器；发送只追加一条 TX 行 |
| LIN | 启动调度按已应用的调度表逐槽生成演示帧（PID、校验和按规范计算）；从节点发布的槽位记「无响应 · 未接线」 |
| UART | 打开串口只开本地会话；发送追加 TX 行，回复来自本窗口的演示应答（help / version / status / read，其余回显） |
| GPIO | 输入电平为模拟值；点输出卡片切换设定，「应用引脚配置」写本地应用记录 |
| AD 记录 | 开始记录按目标采样率生成合成信号样本，按参考电压与分辨率量化；「复制 CSV」只到剪贴板 |
| ADS1015 | 读取转换结果生成演示转换值；显示设置对应的真实配置寄存器字（如 0xC383），不发 I2C |
| EEPROM | 读写都对本窗口的演示镜像执行；任务逐阶段手动推进，报告做读回比较 |
| Flash | 同上，对演示 SPI NOR 镜像；擦除按单元对齐，保留区先备份后恢复；擦除后停止会留下已擦除的保留区 |
| UDS Bootloader · 页面演示 | 六个阶段逐个推进，每阶段追加示例 CAN 报文；报告带执行前配置快照 |
| UDS Bootloader · 真实执行路径（骨架） | P1 宿主任务管理 + 离线导入检查 + **模拟后端**事件；只读示例包或本地 `.udsmock` 文本，不打开总线、不执行包内脚本、不发 UDS 请求。所有状态与结果标「模拟」，不代表任何刷写（见下文「UDS Bootloader P1」） |

## 壳

- 顶栏设备条：品牌、设备弹出字段、固件徽章、刷新、连接/断开。
- 侧栏：设备连接（带状态圆点）在最上；下面三组，组名同 BusStudio HTML：
  - 总线通信：I2C、SPI、CAN、LIN、UART
  - 引脚与采集：PWM / 频率捕获、GPIO、AD 记录、ADS1015
  - 存储与升级：EEPROM、Flash、UDS Bootloader
  
  本地演示在运行的页（CAN 接收、LIN 调度、UART 循环、AD 记录、ADS1015 连续读取、SPI 循环、PWM 输出/捕获演示、EEPROM/Flash/UDS 任务）项尾显示绿点。列表可滚动，底部「外观」（浅色 / 深色 / 跟随系统）与版本号位置固定。
- 底栏状态条：连接状态、空闲/进行中、最近结果的软徽章；右端按页显示接线情况（如「CAN · 本地演示，未接线」「ADS1015 · 模拟数据，不发 I2C」），有演示在运行时追加「演示运行中：…」。
- 演示生成器在 `App::ui` 里每帧推进，与当前打开的页无关，所以切页不会停；窗口被隐藏很久后跳到当前时间，不补发积压。只有按时间推进的演示才请求重绘（50 ms），EEPROM / Flash / UDS 任务靠点击推进，不占 CPU。

## 页面

功能页同一结构（取自 BusStudio）：页头（标题、状态徽章、一行说明、右侧「保存配置」+ 墨色主操作）；左栏「接口配置」卡（字段行、「高级参数 n 项」折叠、卡底「尚未保存 / 参数有修改 / 已保存 · 时间」与「撤销修改」）+ ⓘ 提示；右栏摘要带、工作卡、记录表。窄于断点时两栏改为上下排。说明文字和徽章如实写「演示数据」「本地演示」「未接线」「不经 USB」。

- **设备连接**：设备列表卡，连接信息（状态、序列号、固件、协议版本、端口、速率、单次上限）。只允许一个活动连接；连接设备前必须先断开已有连接，连接操作解除循环。USB 会话失效后要求重新连接，失败写入提示结果未知，不自动重试。
- **I2C · 主机**：
  - 左栏：按能力选择端口、请求速率；目标地址、寄存器地址（可空）、读取长度；高级参数：寄存器宽度（8 / 16 bit，16 bit 高字节先发）、循环周期（20–60000 ms）。
  - 寄存器地址在「写入」「写后读」时放在写入数据前面一起发（仍是一笔 `CMD_I2C`）；「读取」不发。只填寄存器、写入框留空也可以写后读。
  - 「循环」勾选后点任一读写按钮，按周期重复同一笔真实传输；传输失败、设备断开或字段变得无效时自动停止并说明原因。
  - 扫描与恢复在端口控制区调用真实 backend；扫描取消使用独立共享标志，不排在 worker 队列后。事务记录仍支持暂停显示和清空。
- **I2C · 从机**：每端口独立 256 B hex 草稿，显示设备快照代次；仅 Slave 角色可读回/下发，CAS 冲突保留草稿并要求重新读回。角色/配置成功以设备回读为准；失联清除确认状态，不重放。
- **SPI 同步收发**：
  - 左栏：通道、时钟、Mode 0–3、片选、字长；高级：位序、片选有效电平、填充字节。
  - 摘要带：事务、MOSI 字节、估算时长（按时钟数估算）。
  - 发送 MOSI：执行收发、循环（周期可填）、当前片选/模式/时钟徽章。事务详情里 MISO 写「本地记录，无回读数据」。事务记录可暂停显示。
  - ⓘ 提示改为：本页只在本地记录 MOSI，不经 USB，没有 MISO 回读字节。
- **PWM 与频率捕获**：
  - 左侧配置输出，右侧独立捕获，下方时序与设定/示例对比。窄窗口改为上下排。
  - 初始停止、无读数；启停、正常/无信号/中断场景都是本地演示。捕获示例固定为 9998 Hz / 39.98% HIGH 占空比，不模拟物理回读。
  - 比较使用已应用配置版本；低有效占空比自动换算。停止、无信号、中断、恒定输出或等待新版样本时不显示偏差。
  - 无效数字在失焦后保留并阻止应用/保存；停止仍可操作。保存/恢复两侧配置仅在本窗口有效，记录最多 200 条，CSV 只复制到剪贴板。
  - 通道均标「待映射」；数值范围、停止电平、对齐与延时选项均不代表设备能力。详细行为及验收边界见合页说明。
- **CAN 总线监视**（稿 04）：
  - 左栏：硬件通道、仲裁速率、协议模式（经典 CAN / CAN FD）、数据速率、BRS、工作模式（正常 / 只听）、发送帧格式。经典 CAN 或 BRS 关闭时，数据速率跟随仲裁速率；两行仍保留原位置。CAN FD 的数据速率选项为 500 kbit/s、1 / 2 / 4 / 5 / 8 Mbit/s，仅用于本地演示，不代表硬件能力。
  - 高级：过滤 ID、过滤掩码、循环周期、时间显示（相对 / 绝对 UTC）。保存及撤销配置同时包含协议、数据速率和 BRS。
  - 报文监视：时间、方向、ID、协议（CAN / FD / FD+BRS）、类型（STD / EXT）、字节长度、数据、间隔（同协议、方向、ID 和帧格式的上一帧起算）。开头 8 行仍为经典 CAN 示例；CAN FD 接收演示生成 12 / 32 / 64 B 报文。每条记录保留当时的协议、BRS 和 DLC，切换配置不会改写历史。暂停显示只冻结视图，接收继续。
  - 报文详情：记录号、ID、方向、长度、协议、DLC、BRS、帧格式、间隔；字节格支持 D0–D63，可点选查看该字节十进制和 8 个位。长报文也可悬停表格行查看全部 HEX。页面宽于 1100 时详情单独一栏，否则放在左栏配置卡下面。
  - 发送编辑器：两种协议均检查 11 / 29 bit ID；经典 CAN 为 0–8 B，CAN FD 为 0–8、12、16、20、24、32、48、64 B，按 [ST AN5348 的 DLC 表](https://www.st.com/content/st_com/en/technical-documents/an5348-introduction-to-fdcan-peripherals-for-stm32-mcus-stmicroelectronics_asset/chunk-001-topic-an5348-can-fd-protocol-overview.html) 校验，不自动补齐或截断。非法长度不追加 TX 记录；循环中切回经典 CAN 导致数据超长时，下一次界面更新即停止循环，保留编辑内容，切回 CAN FD 不会自动恢复循环。只听模式下发送置灰。
- **LIN 总线调试**（稿 12、14）：
  - 左栏：通道、节点角色（从节点、监听标「需支持」）、波特率、帧 ID、数据长度；高级：校验方式、响应发布方、调度周期、帧超时。
  - 卡头分段切换「帧监视 / 调度表」。帧监视列 ID / PID、校验和、结果；调度表可增删槽位、改帧 ID / 长度 / 发布方 / 时隙，「应用调度表」后生效；旁边「调度信息」卡。
  - 只有主节点能启动调度和发送，其余角色置灰并说明。
- **UART 串口终端**（稿 07）：参数与高级（流控、显示格式、发送行尾、文本编码）；接收终端（文本/HEX、时间戳、暂停显示、清空，自动跟随）；发送（回车发送、行尾、循环周期、按波特率估算的线上时长）。ASCII 编码下含非 ASCII 字符会拒绝发送。
- **GPIO 引脚控制**（稿 06）：输入 / 输出两组卡片，大字电平、「输入读回 · 仅查看」/「输出设定 · 点击切换」、读回电压；未应用的改动标「待应用」，页头按钮显示待应用数。显示格式可切「二进制位图」。应用记录逐引脚写出改了什么。
- **AD 数据记录**（稿 10）：配置条（通道、采样率、参考电压、时长）+「详细配置」展开两列字段；大曲线（最近 240 点，跨度不足 1 s 用 ms）、悬停读数、「样本数据」切表格、暂停显示；图例显示最新电压和原始码值；底栏最小 / 最大值、丢样、状态、复制 CSV。按记录开始后的经过时间采样，到记录时长自动停止；第 k 个样本的时间为 k/rate（k 从 1 开始）。长时间未刷新时最多补齐 4000 个最新样本，其余计入丢样。
- **ADS1015 数据读取**（稿 11）：配置条带 I2C 通道、器件地址、输入、PGA、配置寄存器字；详细配置含数据率、转换模式、比较器、读取间隔。单次模式每点一次读一个值，连续模式按间隔读取。12 位有符号码值、转换寄存器（码值左移 4 位）、超量程标出；底栏显示 LSB。
- **EEPROM 读写**（稿 08）：步骤条「配置与检查 → 执行任务 → 验证与报告」。作业计划分读取/写入；写入按页大小拆段并列出；检查不过时逐条说明。存储内容卡按 128 B 分页，操作范围软底标出。执行卡逐阶段推进、可在安全边界停止；运行时配置与计划锁定，报告给出验证结论、读回数据和执行前配置快照。容量切换保留原演示镜像字节，重新扩大后可查看。
- **Flash 编程**（稿 09、15）：同一流程。作业计划列写入范围、按擦除单元对齐的擦除范围、保留区字节数和编程页数；「存储映射」卡画出擦除范围内的写入区和保留区；「选择文件」置灰（演示用内置示例文件，不读磁盘）。执行任务页即稿 15 的布局。
- **UDS Bootloader 升级**（稿 13、16）：页头下分段切换「页面演示」/「真实执行路径（骨架 · 模拟执行，非真实刷写）」，默认页面演示。
  - 页面演示（原样保留）：承载、速率、请求/响应 ID、固件文件；高级：下载起始地址、STmin、P2、P2*、安全访问。执行时每阶段追加该阶段的示例报文（会话、种子/密钥、擦除例程、请求下载、传输数据、退出、校验、复位、读版本）；报告含最终验证、执行前配置快照（10 项）、可展开的服务交互示例。
  - 真实执行路径（骨架）：顶部琥珀色横幅「模拟执行（非真实刷写）」。左栏「流程来源」（三个内置示例或本地文件路径 →「读取并检查」）与「执行后端」能力声明；右栏「检查结果」（格式/版本/包名/内容哈希、包级与入口级缺失和不支持项、入口表、所选入口的步骤/镜像/参数、「准备运行计划」）、「运行任务」（八个状态、锁定的运行快照、步骤进度与已确认字节分开显示、开始/请求停止/放弃/新建任务、结果）和「事件归档」（序号、时间、运行 ID、来源、步骤、级别、内容）。模拟运行按时间推进，切页不停。

## 与 BusStudio / Magpie 的取舍

- 主色沿用 Magpie indigo（浅 `#4f46e5` / 深 `#a5b4fc`），没有用稿里的 `#6657db`；主按钮墨色，次按钮白底描边，工具按钮无底，状态用圆点和软徽章。
- 稿里的横向页签换成侧栏分组；页内结构（配置卡、摘要带、报文表 + 详情、步骤条、执行卡、配置条 + 大曲线）照稿搬。
- 演示数据、选项范围（通道名、速率档、容量、页大小）是界面上的取值，不代表某块芯片或本设备的能力。
- 「保存配置」保存在本窗口，关闭后不保留，悬停有说明；没有写磁盘，也没加依赖。
- 深浅色选择仍存在一个单词的小文件里（见 `theme.rs`）。

## 新增控件与模块

- `widgets.rs`：`check`（墨色勾选框）、`kv`（详情键值行）、`steps`（三步步骤条）、`progress`、`with_side`（右侧定宽栏）、`tab_panel`（卡头分段切换）、`muted`、`error`。
- `local.rs`：`Saved`（保存配置快照与卡底状态）、`Ticker`（演示生成器节拍，长时间隐藏后跳过积压）、`Noise`（可复现的演示噪声）、十六进制/数字解析。
- `chart.rs`：曲线（网格、刻度、填充、少量点时画圆点、悬停读数）、配置条、图例。
- `frame.rs`：CAN/LIN 共用的字节格、时间与间隔格式。
- `job.rs`：EEPROM/Flash/UDS 共用的步骤条、页头主按钮、文件行、作业计划、检查结论、执行卡、hex 行。UDS 真实执行路径只借用其中的 `line`、`plan`、`range_text` 显示函数，不使用 `job::Task`，`job.rs` 未改。
- `flow.rs`、`flow/`：UDS Bootloader P1 的版本化后端接口、宿主任务管理和模拟后端，见下节。

## UDS Bootloader P1（宿主 + 离线导入 + 模拟后端）

依据 [`docs/uds-bootloader-plugin-proposal.md`](../../../docs/uds-bootloader-plugin-proposal.md) §4.2–4.3、§5.1、§5.3、§7 与 §8 的 P1 行。**本阶段只有宿主和模拟后端**：没有真实 CAN / ISO-TP / UDS 通信，没有刷写任何 ECU，模拟运行的「成功」不是刷写成功。提案 §10 的 D01–D07 全部**仍待确认**，本实现没有替用户作出其中任何选择；模拟包格式也不代表首个真实流程资产（D01）。

- `flow/api.rs`：接口版本 `0.1`（1.0 之前主次版本都须一致）。`Backend` trait：`capabilities` / `inspect` / `prepare` / `start` / `request_cancel` / `result`，外加 `poll` 收取 `start` 之后的事件。所有调用立即返回，界面线程不等待目标。`Mode` 区分模拟与真实硬件；`Hardware` 只是预留，P1 宿主拒绝接入非模拟后端，也不采用与运行计划模式不一致的结果（记为结果未知）。
- `flow/host.rs`：任务状态 准备中 / 就绪 / 运行中 / 停止处理中 / 成功 / 失败 / 已停止 / 结果未知，转换表见 `State::can_go`（终态无出口；已停止只能经停止处理中到达）。
  - 准备：必须给出入口，包内有多个入口时不默认第一个；任何缺少依赖或不支持项都拒绝准备，也就不能启动。运行计划由后端返回后锁定，宿主只给出 `&RunPlan`。
  - 启动：只从「就绪」启动一次；启动前重新读取流程文件并比对 FNV-1a 64 哈希（非加密，只用于发现改动），不一致则作废计划、要求重新检查。失败或未知结果不自动重试。
  - 停止：后端「接收」停止请求只把任务转为停止处理中，界面和归档写明这不表示 ECU 已停止、也不表示回滚，终态以后端结果为准。
  - 事件归档：每条有运行 ID（启动后）、任务内递增序号、时间、步骤、级别、来源（宿主/后端）和内容；步骤进度与已确认下载字节分开记录。
  - 导入上限 256 KiB；只读文本，不解包、不执行。一次只有一个任务（单 ECU、单通道）。
- `flow/mock.rs`：`MockBackend`，读 `uds-mock-fixture` v1 文本格式（P1 自拟，说明见 [`fixtures/uds/README.md`](fixtures/uds/README.md)），内置 `single` / `multi` / `blocked` 三个示例。每步 700 ms，下载分 4 段报告确认字节；`simulate = fail@X` / `lost@X` 演示失败与后端失联（结果未知）；停止规则：下载中途停止不等待在途段 → 结果未知，其他步骤完成后停止 → 已停止并列出已发生的副作用。全部事件文本以「模拟」开头。
- `uds/sim.rs`：上述界面。和页面演示的 `Uds` 字段、`STAGES`、`stage_frames` 完全分开。
- 不改的东西：USB 协议、固件、`usb-i2c` crate、`worker.rs`、`job.rs`、`Cargo.toml` / `Cargo.lock`；没有新增依赖。`flow::tests::host_path_never_reaches_usb_or_processes` 检查 `flow/` 和 `uds/sim.rs` 不引用 USB 工作线程、桥接 crate、子进程或网络。
- 字体子集：示例包里的中文也显示在界面上，`subset.sh` 与 `fonts::tests::subset_covers_ui_text` 现在同时扫描 `fixtures/` 下的 `.udsmock`。
- 未做（P2 及以后）：真实执行后端与 IPC 进程、CAN / ISO-TP / UDS 通信、读取 ECU 标识与目标匹配（§5.1 第 4 步）、镜像内容与地址/签名检查、算法组件、后端失联看门狗、报告持久化与导出、真机/台架验证。

### JSON 流程清单解析层（`uds-flow-manifest` v1，PR A）
